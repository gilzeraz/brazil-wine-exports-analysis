# Brazil Wine Exports Analysis

Business Intelligence and Data Analytics project focused on analyzing Brazilian wine exports over the last 15 years.

This project explores export trends, destination countries, market behavior, and external economic factors that may influence wine exports from Brazil to the global market.

---

# Objective

The main objective of this project is to analyze Brazilian wine export data and generate strategic insights for investors and stakeholders through:

- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Intelligence techniques
- Market trend analysis
- External factor correlation

The analysis includes:

- Export volume (liters)
- Export value (US$)
- Destination countries
- Historical evolution
- Market growth opportunities
- Future projections
